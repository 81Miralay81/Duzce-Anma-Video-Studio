# Düzce Anma Video Stüdyosu

Android-first, ücretsiz ve açık kaynaklı bir anma videosu hazırlama uygulaması.

## Hedef
- Android telefondan fotoğraf seçme ve sıralama
- 9:16 dikey anma videosu projesi hazırlama
- Başlık, ara yazı ve kapanış kartı düzenleme
- Fotoğraf ve sesleri projeye ekleme
- MP4 dışa aktarma (sonraki geliştirme aşaması)

## Geliştirme
Bu depo Android APK hedefli bir projedir. Ücretli API veya abonelik gerektirmez.
Arşiv fotoğraflarını yalnızca kullanım izni/lisansı uygun olduğunda ekleyin.
AI ile oluşturulmuş görselleri gerçek arşiv fotoğrafı gibi sunmayın; gerektiğinde
"CANLANDIRMA" olarak belirtin.

## APK
GitHub Actions, Android debug APK'sını derler ve Actions çıktısına artifact olarak ekler.
